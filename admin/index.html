Sign in to edit your articles

This page edits the articles kept in your private GitHub folder. Only someone holding your sign-in key can use it.

First time on this device?

  1. Open GitHub's "new key" page (you must be signed in to GitHub).
  2. Under Repository access, choose Only select repositories and pick site-content.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy the key, and paste it below.
